# 구글시트 + Apps Script 메뉴 관리 연동

관리자가 **코드를 만지지 않고 구글시트만 수정**하면 홈페이지의 주간 메뉴·메뉴판이
자동으로 바뀌도록 연결하는 방법입니다. (이미지도 시트에 링크만 넣으면 됩니다.)

```
[관리자가 구글시트 수정]
        │
        ▼
[Apps Script 웹앱(doGet) → JSON]
        │  SHEETS_API_URL
        ▼
[Next.js 사이트(ISR, 5분마다 재검증)] → 화면 반영
```

## 1. 구글시트 만들기

새 구글시트를 만들고 아래 두 개의 탭(시트)을 추가합니다. **첫 행은 헤더**입니다.

### 시트 ①: `주간메뉴` (월~금 오늘의 백반)

| 요일 | 날짜 | 대표메뉴 | 이미지URL | 반찬 | 가격 | 품절 |
|---|---|---|---|---|---|---|
| 월 | 6월 9일 | 제육볶음 백반 | https://… | 제육볶음, 된장찌개, 계란말이, 김치 | 11000 | |
| 화 | 6월 10일 | 고등어구이 백반 | https://… | 고등어구이, 강된장, 콩나물국, 김치 | 11000 | |
| 수 | | 청국장 백반 | | 청국장, 나물 3종, 두부조림, 김치 | 10000 | |
| 목 | | 불고기 백반 | | 소불고기, 잡채, 미역국, 김치 | 12000 | |
| 금 | | 생선조림 백반 | | 코다리조림, 호박전, 무생채, 김치 | 12000 | 예 |

- **요일**: `월/화/수/목/금` (또는 `mon~fri`)
- **반찬**: 쉼표(,) 또는 줄바꿈으로 구분
- **가격**: 숫자만 (원 단위)
- **품절**: 품절이면 `예` / `O` / `품절` 입력, 아니면 비워둠

### 시트 ②: `메뉴판` (상시 메뉴/가격표)

| 분류 | 메뉴명 | 가격 | 설명 | 추천 |
|---|---|---|---|---|
| 백반 정식 | 백선당 정식 | 12000 | 오늘의 국과 7가지 반찬 | 예 |
| 백반 정식 | 제육 백반 | 11000 | 직접 양념한 제육볶음 | 예 |
| 단품 · 식사 | 된장찌개 | 8000 | 두부와 애호박이 푸짐한 | |
| 반찬 · 추가 | 계란말이 | 6000 | 도톰하게 부쳐낸 | |

- 같은 **분류**끼리 자동으로 묶여 탭으로 표시됩니다. (행 순서가 표시 순서)
- **추천**: 추천 메뉴면 `예`, 아니면 비워둠

### 이미지 넣는 법

- 외부 이미지 URL을 그대로 붙여넣거나,
- 구글 드라이브에 사진을 올리고 **공유 링크**(보기 권한: 링크가 있는 모든 사용자)를
  `이미지URL` 칸에 붙여넣으면 됩니다. 스크립트가 자동으로 표시용 URL로 변환합니다.

## 2. Apps Script 웹앱 배포

1. 구글시트에서 **확장 프로그램 → Apps Script** 클릭
2. 기본 `Code.gs` 내용을 지우고, 이 폴더의 [`Code.gs`](./Code.gs) 내용을 붙여넣고 저장
3. 우측 상단 **배포 → 새 배포** 클릭
4. 유형 선택(톱니바퀴) → **웹 앱**
5. 설정:
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
6. **배포** → 권한 승인 → 생성된 **웹 앱 URL** 복사
   (형식: `https://script.google.com/macros/s/XXXX/exec`)

> 시트 구조나 코드를 바꾸면 **배포 → 배포 관리 → 편집(연필) → 새 버전 → 배포**로 갱신하세요.

## 3. 사이트에 URL 연결 (Vercel 환경변수)

Vercel 프로젝트 → **Settings → Environment Variables** 에 추가:

| Key | Value |
|---|---|
| `SHEETS_API_URL` | 위에서 복사한 웹 앱 URL (`…/exec`) |

저장 후 재배포하면 연동됩니다. 이후에는 **시트만 수정**하면 (재배포 없이) 최대
5분 내에 사이트에 반영됩니다.

로컬 개발 시에는 프로젝트 루트에 `.env.local` 파일을 만들고
`SHEETS_API_URL=...` 한 줄을 넣으면 됩니다. (`.env.local.example` 참고)

## 동작 방식 / 폴백

- `SHEETS_API_URL` 이 없거나 호출에 실패하면, 사이트는 **샘플 데이터**로 안전하게
  표시됩니다. (빈 화면이 되지 않습니다.)
- 정규화 로직은 `src/lib/sheets.ts` 에 있습니다.
